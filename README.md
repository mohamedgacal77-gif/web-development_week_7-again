# SpendWise

## Project Description

SpendWise is a personal expense-tracking web application designed to help users organize their spending and manage their budgets.

This project demonstrates how to publish a website using GitHub and Netlify, configure a meaningful Netlify subdomain, and maintain the live website through continuous deployment.

## Technologies Used

- HTML5 — page structure and content
- CSS3 — styling, layout, and responsive design
- JavaScript — application functionality and user interactions
- Git — version control
- GitHub — source code hosting
- Netlify — website hosting and continuous deployment
